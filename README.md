A fantasy conqueror directs a siege from a stool carved out of a saint's gallows. In 99 words, small corrections, broken orders, and a request for quiet betray the fatigue beneath the threats. The city's fate rests on when its conqueror chooses to stand.

Run `python3 main.py` to write `out/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to choose another output directory. The UTF-8 output has no trailing newline. Drafts and criterion scores are recorded in [CANDIDATES.md](CANDIDATES.md).

Verified with both the default directory and a temporary output directory: 99 words, 534 characters, identical bytes. SHA-256: `ea0082045adadad0e5c921a25507df2c673585ba30ca31ae3d99d8190c1f77d4`.
